# Specification

## Summary
**Goal:** Build a premium, dreamy, single-page romantic proposal website for Urvi Ji with animations, a photo gallery using the provided images, background music controls, and an interactive proposal moment.

**Planned changes:**
- Apply a cohesive romantic theme (blush pink/red/white with gold accents), soft glow/gradients, consistent typography (elegant serif headings + handwritten-style for personal messages).
- Create a hero section with exact text (“Hey Urvi Ji ❤️” + the provided subtext), a visible looping heart-beat animation, and subtle entrance animation.
- Add ambient background effects: floating hearts + gently falling rose petals with soft blur/glow, with reduced-motion support and/or an on-page toggle.
- Add romantic instrumental background music with clear play/pause and mute/volume behavior that respects autoplay policies and persists choice for the session.
- Build a “Love Story” timeline/card section with three items: “How we met”, “Why she is special”, and “How she calls me ‘good boy’ and how that makes me feel loved”, using English placeholder copy and gentle scroll-in animations.
- Implement a Photo Gallery carousel/slider styled with rounded corners, subtle shadows, and cinematic transitions; preload the two uploaded images and allow session-only client-side adding of more photos.
- Add a “Message From Me” section showing the exact handwritten-style quote with subtle paper/ink styling and scroll-in animation.
- Create a highlighted Proposal section with exact glowing text, two animated buttons (“💖 YES”, “😜 Of course YES”), and on-click heart-burst celebration + modal with the exact message; modal is dismissible and accessible.
- Add a footer with the exact text “Made with endless love by Mann”.
- Implement smooth single-page navigation/scroll behavior and a “Copy link” control that copies the current URL with user feedback; ensure mobile responsiveness and fast loading.

**User-visible outcome:** Visitors can scroll through a romantic single-page experience with animated hearts/petals, play/mute background music, view and add photos to a gallery for the session, read love story/message sections, and click a proposal CTA that triggers a celebration and a sweet pop-up message, then share the page link.
